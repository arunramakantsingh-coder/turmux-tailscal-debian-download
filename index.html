First-time setup

  1. Install the official Termux app from GitHub Releases or F-Droid. Do not mix Termux sources.
  2. Install and open Alpha7A.
  3. Allow Termux external commands and grant Alpha7A the Termux RUN_COMMAND permission.
  4. Tap START ALPHA7A PROVISIONING. The build supplies the configured Tailscale auth key automatically.

Provisioned services

Termux tools, Tailscale userspace, unique hostname, SSH on 8022, Debian via proot-distro, Debian SSH on 2222, SOCKS5 on 1055, local operations page on 8080, Git/Git LFS/Python/build tooling and diagnostics.

Android restriction: Android still requires user confirmation to install an APK and Termux security approvals before a third-party app can run commands in Termux.
